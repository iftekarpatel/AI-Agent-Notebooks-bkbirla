How to work through a lab
  1. Open a new Google Colab notebook for each experiment.
  2. Add your API keys once in Colab Secrets (key icon in the left sidebar). The Hugging Face lab needs no key, only the T4 GPU runtime.
  3. Copy each step, run it with Shift + Enter, and compare with the expected result.
