Agentic AI Lab Practicals: Groq edition

Three experiments built with the OpenAI Agents SDK, running on free models from Groq. Copy each step into your own Colab notebook, run it, and compare your result with the expected one.

Think of it like a phone and a SIM card: the Agents SDK is the phone, the AI provider is the SIM. We swap the OpenAI SIM for a free Groq SIM. The phone and its apps (agents, memory, tools) work the same; only the network address and the plan name change.

Before you start

  1. Open colab.research.google.com and create a new notebook for each experiment.
  2. Add your keys once in Colab Secrets: click the key icon in the left sidebar, then + Add new secret. Use the exact names below and switch Notebook access on.
  3. For every step: click Copy, paste into a new code cell, press Shift + Enter, then open Expected result and compare.
  4. Run the steps in order. If Colab restarts, run all earlier steps again from the top.

If something goes wrong

SecretNotFoundError / key not found
Check the secret name is exactly as in the table above and that Notebook access is switched on for it.
"Restart session" after installing
Click it, then continue from the step after the install. You don't need to install again.
NameError: name '…' is not defined
An earlier step was skipped or Colab restarted. Run the steps again from the top, in order.
429 Too Many Requests
Groq's free plan allows about 30 requests and 8,000 tokens per minute for each model, per key. Wait one minute and re-run. Don't share one key across the class: each student needs their own.
404 model not found
Model names change. Run the "list the available ones" step in Experiment G1 and use a name from that list. Always wrap the name with groq(…): a plain "openai/gpt-oss-20b" string gets shortened and also gives 404.
Tool 'browser.search' not found (Experiment G3)
The gpt-oss models sometimes try a tool name they learned in training. With run_config in place the agent is told, tries again with the right tool, and the run carries on. If it gives up, re-run the cell.
Warning: OPENAI_API_KEY is not set, skipping trace export
The connect step was skipped. Run it again: it switches tracing off with set_tracing_disabled(True).
