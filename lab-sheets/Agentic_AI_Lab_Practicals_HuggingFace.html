Agentic AI Lab Practicals: Hugging Face edition

Experiment 1 built with the OpenAI Agents SDK, running on free open-source models downloaded from Hugging Face. Copy each step into your own Colab notebook, run it, and compare your result with the expected one.

Think of it like eating out versus cooking at home: OpenAI, Gemini and Groq are restaurants. You order through a waiter (the API key) and the kitchen is theirs. Here we cook at home. Hugging Face is the free recipe library, the Qwen model is the recipe, Ollama is the cook, and Colab's free GPU is the stove. The Agents SDK still places the order the same way; it just sends it to your own kitchen.

Before you start

  1. Open colab.research.google.com and create a new notebook for each experiment.
  2. Add your keys once in Colab Secrets: click the key icon in the left sidebar, then + Add new secret. Use the exact names below and switch Notebook access on.
  3. For every step: click Copy, paste into a new code cell, press Shift + Enter, then open Expected result and compare.
  4. Run the steps in order. If Colab restarts, run all earlier steps again from the top.

If something goes wrong

"command not found" for nvidia-smi, or answers take minutes
The GPU is off and the model is running on the CPU. Runtime → Change runtime type → T4 GPU → Save, then run all steps again from the top.
"Restart session" after installing
Click it, then continue from the step after the install. You don't need to install again.
APIConnectionError / Connection refused
The Ollama server is not running, usually after a restart. Run Step 4 again; the downloaded models are still there.
404 model not found
The model name doesn't match a downloaded model. Run Step 7 and copy a name exactly from its list, or run Step 5 again.
NameError: name '…' is not defined
An earlier step was skipped or Colab restarted. Run the steps again from the top, in order.
Answer has no ✅ / ❌ prefix
Small models follow formatting rules less strictly. Run it again, or use HF_BIG_MODEL.
Colab disconnected and everything is gone
A free Colab session is wiped after it disconnects. Start again from Step 1; the downloads take a few minutes.
402 Payment Required (optional cloud step)
The Hugging Face account has no credits. Use the local models (Steps 1–17) instead.
